# CCNA 1 Exam Prep (EN / RU / KK)

Статический сайт, сервер не нужен. Открывается и двойным кликом по `index.html`.

## Деплой на GitHub Pages
1. Создай репозиторий на GitHub и загрузи все файлы из этой папки (`index.html`, `css/`, `js/`, `data/`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://<твой-логин>.github.io/<репозиторий>/`.

## Как добавлять переводы
Переводы лежат в `data/ru.js` и `data/kk.js`: `"<id вопроса>": {"q": "вопрос", "o": ["вариант1", ...], "e": "объяснение"}`.
Вопросы на английском — в `data/questions.js` (`a` — индекс или массив индексов правильных ответов, нумерация с 0).
Если у вопроса нет перевода, сайт показывает английский вариант.
